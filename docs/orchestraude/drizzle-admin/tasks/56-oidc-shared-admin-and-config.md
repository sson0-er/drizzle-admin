# Task 56: oidc-shared-admin-and-config

## Goal
OIDC SSO example, part 1 (decision 053 points 1, 2, 3, 5, 9, 12, 15). This task adds the pure, unit-testable building blocks and the TLS guard. It does not add the OIDC app or the mock IdP:
- `example/app.ts` exports `createExampleAdmin({ secret, auth })`. `createExampleApp` keeps its signature and behavior and calls it.
- New modules `example/oidc/return-path.ts` (`safeReturnPath`), `example/oidc/allowlist.ts` (`parseAllowlist`, `isAllowed`), `example/oidc/mode.ts` (`selectMode`, `assertTlsVerificationOn`) and `example/oidc/config.ts` (`readOidcExampleConfig`).
- The four OIDC devDependencies are pinned exactly in package.json, and `pnpm-lock.yaml` matches. `config.ts` already imports the `OidcAuthEnv` type, so they are needed here. The published package does not change.
- `test/example-oidc.test.ts` holds the unit tables for these modules. `test/tls-verification.test.ts` holds the static guard, the `mode.ts` single-occurrence check, the `assertTlsVerificationOn` rows and the worker environment check.

The OIDC app, the mock IdP, the certificate module and the vitest global setup come in task 57. The launcher, server, `example:oidc` script, README and CLAUDE.md come in task 58.
