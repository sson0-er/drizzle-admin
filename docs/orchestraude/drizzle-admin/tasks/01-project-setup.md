# Task 01: project-setup

## Goal
A clean checkout can run `pnpm install`, and `pnpm test`, `pnpm typecheck`, `pnpm lint` and `pnpm build` all pass. `scripts/verify.sh` runs all four commands and is the verify gate for every later task. `src/messages.ts` (all Japanese UI strings) exists with its unit test, so the test run has at least one real test.

## Scope
### Files to touch
- package.json, pnpm-lock.yaml (generated by `pnpm install`)
- tsconfig.json, tsconfig.build.json, biome.json, vitest.config.ts, .gitignore, LICENSE
- scripts/verify.sh (new, executable)
- src/index.ts (placeholder `export {};`, replaced in task 04)
- src/messages.ts
- test/messages.test.ts
### Do not touch
- mise.toml (user-managed, decision 001; node 24.21.0 and pnpm 12.10.0 are already pinned)
- docs/** (except appending to this task's History)
- README.md (written in task 26)
- Any other file under src/, test/ or example/

## Implementation notes
- Follow `interfaces/project-setup.md` exactly for package.json (fields, scripts table, dependency versions; devDependencies are exact versions), tsconfig.json, tsconfig.build.json, biome.json, vitest.config.ts, .gitignore and LICENSE. No `packageManager` field. Do not add `repository`/`homepage`.
- Run pnpm through mise: `mise exec -- pnpm install` (or a mise-activated shell).
- `scripts/verify.sh`: bash, `set -euo pipefail`, `cd "$(dirname "$0")/.."`. Use `mise exec -- pnpm` when `mise` is on PATH, otherwise `pnpm`. Run, in this order: `test`, `typecheck`, `lint`, `build`. Print a header line before each command. The first failing command makes the script exit non-zero. `chmod +x` it.
- Biome 2.5 config keys: check them against the installed schema (`node_modules/@biomejs/biome/configuration_schema.json`) or `biome migrate`, as project-setup.md asks. If `biome check .` reports diagnostics for files under `docs/` (orchestration artifacts, not source), add `"!docs"` to `files.includes` and record that in History.
- If `pnpm install` reports ignored dependency build scripts that break a tool, allow that package explicitly in pnpm's config (project-setup.md) and write a decision file under `docs/orchestraude/decisions/` with the reason. This is the only allowed docs change besides History.
- `src/index.ts` is a placeholder (`export {};`) so `tsc -p tsconfig.build.json` has an input. Task 04 replaces it.
- `src/messages.ts`: copy the `messages` object from `interfaces/support.md` (keys are referenced by other components and by tests). No other UI text literal belongs anywhere else in src.
- `pnpm build` must emit `dist/index.js` and `dist/index.d.ts`.
