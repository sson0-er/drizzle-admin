# Design review history

## Revision 1 (2026-10-07), response to 03-design-review.md (high 0, medium 2, low 7)

User instruction for this round: address both medium findings, address low findings if cheap, and record the user decision on hono/csrf origin equality.

- [medium] PG ilike fails on non-text string-kind and pgEnum search columns: **addressed.** A probe confirmed SQLSTATE 42883 on uuid, numeric, interval, string-mode timestamp, both date modes and pgEnum, and that `ilike(sql\`${col}::text\`, pattern)` works on all of them (evidence: 2026-10-07-pg-search-non-text-columns). Decision 018 adopts the cast for every PG search column. The `isTextLike` + reject alternative was rejected because it would forbid useful uuid/numeric/enum search. Decision 009 was updated. Changed files: data.md, test-strategy.md (PG `events` fixture, query and repository tests, integration search case), README.md.
- [medium] Date-only (PgDate mode:date) values are shifted by the configured time zone: **addressed.** The probe and source reading confirmed the reviewer's description. PgDate writes `toISOString()` and reads `YYYY-MM-DD` as UTC midnight. A Tokyo-midnight Date was stored as the previous day, and UTC-midnight Dates round-tripped under every process TZ (evidence: 2026-10-07-drizzle-pg-date-mapping). Decision 019: date-only values are UTC-midnight calendar dates. `parseDateOnly` / `toDateOnly` / the new `formatDate` take no time zone. The new `calendarPresetRange` uses the tz only to pick "today". Coercion, `toFormValue` and formatting key on `isDateOnly`. Changed files: support.md, forms.md, data.md, views.md, introspect.md, test-strategy.md (unit cases and a PG round trip under Asia/Tokyo and America/New_York), README.md.
- [low] Sub-app notFound is not used when admin.app is mounted: **addressed.** Route 11 `ALL /*` renders the 404 page and travels with the mounted app (decision 022). Hono's sub-app `notFound` behaviour itself remains unverified, and the design no longer relies on it. Changed files: routes.md, README.md, test-strategy.md.
- [low] formatCell rule order leaves FK label precedence ambiguous: **addressed.** Rules are numbered and applied in order. `fkLabel` comes right after null handling, and date-only formatting was added. Changed files: views.md, test-strategy.md.
- [low] Widget overrides incompatible with the field kind are unspecified: **addressed.** Decision 021 adds an `allowedWidgets(meta)` table checked by `register()`, and a finalization check for FK `select` without a registered target. Data handling depends only on the field, never on the widget. Changed files: forms.md, admin.md, test-strategy.md.
- [low] Change handler does not mention FK choices; DeletePage prop name mismatch: **addressed.** Change step 2 now computes FK choices as Add step 2. The Delete handler passes `{ modelLabel, objectLabel, cancelHref }`. Changed file: routes-handlers.md.
- [low] Origin-check 403 body is not the layout error page: **addressed.** `onError` renders `ErrorPage` for an `HTTPException` (`csrfFailed` for 403) with a minimal chrome, because the session has not run yet. `renderPage` gains `opts.minimal` (decision 022). Changed files: routes.md, routes-handlers.md, README.md, test-strategy.md.
- [low] 500 log line drops message and stack for non-DB errors: **addressed.** New `isDbError` (`instanceof DrizzleQueryError` or a string `code` in the cause chain) selects redacted logging. Every other error is logged in full (decision 022). Changed files: data.md, routes.md, README.md, test-strategy.md.
- [low] Phase 1 example smoke test expects pages that do not exist yet: **addressed.** The smoke test grows by phase. Phase 1 checks that `createExampleApp()` resolves and that `GET /` returns 302 to `/admin/`. The manual `pnpm example` start check is reported separately. Changed file: test-strategy.md.

Also recorded in this round:
- User decision: hono/csrf string-`origin` exact equality stays unverified at design time and must be proven by implementation tests (different port, trailing slash, longer host, different scheme → 403). A deviation means the task is blocked (decision 020; auth.md, test-strategy.md, questions.md "Resolved questions").
- New open question Q5 (proposal): a date widget and date-preset filter for PG string-mode `date()` columns. It is not implemented, because it goes beyond the requirements.
