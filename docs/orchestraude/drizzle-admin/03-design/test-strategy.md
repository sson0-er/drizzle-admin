# Test strategy

All tests live in `test/` and run with `pnpm test` (vitest 5). Integration tests use `app.request()` / `admin.fetch()` and are parameterized over in-memory SQLite (better-sqlite3) and PGlite (`describe.each(dialects)`). HTML assertions check specific elements through the stable selectors in [interfaces/views.md](interfaces/views.md); there are no full-page snapshots.

## Helpers (`test/helpers/`)
Changed 2026-10-07: PG-only `events` fixture table for non-text search and date-only values (decisions 018, 019).
Changed 2026-10-07: `events.due` (`date()` string mode) added for date-only strings (decision 023).
Changed 2026-10-07: the bigint column type per dialect is named; SQLite `articles.big` is `blob({ mode: "bigint" })` (decision 026).

- `db.ts`: `export const dialects: DialectFixture[]`, where `DialectFixture = { name: "sqlite" | "pglite"; dialect; setup(opts?: { logger? }): Promise<{ db; schema; close(); queryCount(): number }> }`. Each setup creates fresh tables from constant DDL (`test/fixtures/ddl-sqlite.sql.ts`, `ddl-pg.sql.ts`) that matches the drizzle schemas, then inserts the fixture rows. Query counting uses a Drizzle custom logger (`{ logQuery() { n++ } }`).
- `fixtures/schema-sqlite.ts`, `fixtures/schema-pg.ts`: logically equal tables with the same property keys. `authors` (id auto, name text notNull unique, email, active boolean, role enum, createdAt timestamp default), `articles` (id auto, title notNull, body long text, authorId FK → authors notNull, publishedAt timestamp nullable, meta json, views integer, score real, big bigint) and `kv` (text PK, value). `articles.big` is `bigint("big", { mode: "bigint" })` on PG and `blob("big", { mode: "bigint" })` on SQLite, because SQLite `integer()` has no bigint mode; the SQLite DDL declares it `big BLOB` (decision 026). The PG schema additionally covers `text` vs `varchar`, `uuid`, `date()`, `date({mode:"date"})` and identity for introspection. It also has a PG-only table `events` (id serial, `day` `date({mode:"date"})` notNull, `code` uuid defaultRandom notNull, `amount` numeric, `mood` pgEnum `mood` (`calm`, `busy`), `note` text, `due` `date()` nullable (string mode)), which is used by the PG-only cases below (`describe` runs for `pglite` only).
- `app.ts`: `makeAdmin(fixture, overrides)` returns `{ admin, client }`. `client` is a cookie-jar wrapper around `admin.fetch` that sends `Origin: http://localhost` on POST, plus `login()`, `get(path)`, `post(path, form, { withToken = true })` and `csrf()` (reads the token from the last page's `_csrf` input).
- `html.ts`: parse5-based `parse(html)`, `qsa(root, { tag, id?, cls?, attrs? })`, `qs`, `text(node)`, `attr(node, name)`.
