Learned:
- Latest on 2026-10-09: @hono/oidc-auth 1.10.0, oidc-provider 9.12.2, selfsigned 5.5.0 (unchanged since the research), @types/oidc-provider 9.12.1 (deps @types/koa, @types/node, @types/keygrip at "*"). selfsigned 5.5.0 ships `index.d.ts`.
- @hono/oidc-auth 1.10.0: `exports["."]` has only `import` (./dist/index.mjs) and `require`; `dist/index.d.mts` sits next to index.mjs (top-level `types` points at the .d.cts). `initOidcAuthMiddleware(config: Partial<OidcAuthEnv>)`; `OidcAuthEnv` is exported as a type (OIDC_AUTH_SECRET, OIDC_ISSUER, OIDC_CLIENT_ID, OIDC_CLIENT_SECRET required; the rest optional). `getAuth(c): Promise<OidcAuth | null>`, `OidcAuth` = `{ rtk, rtkexp, ssnexp }` plus `OidcAuthClaims` (`sub?`, `email?`, other JSON claims). `processOAuthCallback(c)` deletes the state/nonce/code_verifier/continue cookies and redirects; `revokeSession(c)` deletes the session cookie. The d.ts augments hono's `ContextVariableMap` (keys oidcAuthEnv, oidcAuthorizationServer, oidcClient, oidcAuth, oidcAuthJwt, oidcClaimsHook, oidcAuthRefreshErrorHook, oidcClientAuth).
- `dist/index.mjs` 1.10.0: the authorization request uses `redirect_uri = new URL(OIDC_REDIRECT_URI, c.req.url)` (a path-only value follows the request's Host); token, refresh and revocation requests authenticate with `ClientSecretBasic(OIDC_CLIENT_SECRET)` unless `oidcClientAuth` is set; `scopes_supported` must be non-empty and contain every `OIDC_SCOPES` entry (else 500).
- Claims hook (read 2026-10-10): `updateAuth` spreads the result of `c.get("oidcClaimsHook")` (default: `{ sub: claims?.sub || orig?.sub || "", email: claims?.email || orig?.email || "" }`, where `claims` are the validated ID token claims and `orig` the previous session) into the session JWT, then adds `rtk`, `rtkexp`, `ssnexp`; it runs on the callback and on each refresh.
- Config resolution (read 2026-10-10): `setOidcAuthEnv` takes each key as `config?.KEY ?? env(c).KEY`, so only `undefined`/`null` falls back to `process.env`; an empty string is kept. `OIDC_COOKIE_DOMAIN`, `OIDC_AUDIENCE` and `OIDC_AUTH_EXTERNAL_URL` are used only when truthy (hono's serializer also writes `Domain` only when truthy), so `""` means unset. Defaults filled afterwards: redirect `/callback`, cookie path `/`, name `oidc-auth`, refresh 900, expires 86400, scopes `""` (= every supported scope), alg HS256.
- `processOAuthCallback` (read 2026-10-10): deletes `state` first, then validates; an IdP error response becomes `HTTPException(500, { message: "OAuth2Error: [<error>] <error_description>" })`; missing `code`/`nonce`/`code_verifier` gives `HTTPException(500, "Missing required parameters / cookies")`; `nonce`, `code_verifier`, `continue` are deleted only after state validation passes. Hono's default error handler answers an `HTTPException` with its message as the body.
- engines: koa 3.2.1 `>=18`, pkijs 3.3.3 `>=16`, @peculiar/x509 1.14.2 `>=22` (2.1.0 `>=20`), debug `>=6`; oauth4webapi 3.8.8 and jose 6.2.10 none. oidc-provider 9.12.2 and selfsigned 5.5.0 declare no install/postinstall scripts.
