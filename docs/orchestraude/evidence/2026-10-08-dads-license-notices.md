Learned:
- Code snippets (GitHub, digital-go-jp) are MIT. Notices page: if edited/processed and used in the user's own site, no attribution required; if used unmodified and published, cite "出典：デジタル庁デザインシステムウェブサイト https://design.digital.go.jp/dads/ およびデジタル庁GitHub https://github.com/digital-go-jp".
- Design system body (guidelines/docs, excluding Figma and snippets): attribution required; processed content must say so and must not look as if made by the Digital Agency; otherwise follow the Digital Agency copyright policy (not read).
- Figma data: CC BY 4.0; includes some Material Symbols icons under Apache License 2.0. Illustration/icon assets follow a separate "イラストレーション・アイコン素材利用規約".
- Third-party: Noto Sans under SIL OFL 1.1 (Copyright 2022 The Noto Project Authors); the DADS site uses subsetted font data. OFL: may bundle/redistribute with software if copyright notice and license text accompany each copy; font may not be sold by itself; no Reserved Font Name for modified versions.
- LICENSE of the snippets repo (Copyright (c) 2025 デジタル庁) and of @digital-go-jp/design-tokens (Copyright (c) 2023 デジタル庁) are plain MIT, read from the cloned repo and the npm tarball.
Not confirmed: the Digital Agency copyright policy text; whether the notices page text is legally binding beyond the repo LICENSE (legal opinion not sought). Page text was read via HTML-to-text conversion, not rendered.
